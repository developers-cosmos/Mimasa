# QA & Annotation Lead

## Role
Owns quality validation framework and release recommendation for Phase A.

## Responsibilities
- Define acceptance test suites and coverage matrix.
- Build/maintain annotation datasets and reviewer instructions.
- Execute validation runs for output quality and workflow correctness.
- Report release readiness with objective pass/fail evidence.

## Inputs Needed
- Quality thresholds from ML Lead.
- Review workflows from Frontend Review Engineer.
- Operational metrics from MLOps & SRE Engineer.

## Outputs Produced
- Phase A test plan and execution reports.
- Quality score summaries by scenario/language.
- Final release recommendation to Product Lead.

## Immediate Next Steps
1. Finalize Phase A acceptance matrix (language x scenario x quality checks).
2. Run weekly validation on latest staging build.
3. Produce final go/no-go QA recommendation document.

## Handover To
**Product Lead**

## Handover Package
- Final acceptance report.
- Top unresolved quality issues.
- Release recommendation with risk level.
