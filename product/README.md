# Product Workspace

This folder contains product-facing planning, governance, and team execution artifacts.

## Structure

- `strategy/`
  - `research.md` — business/problem research
  - `architecture.md` — target system architecture
  - `implementation-plan.md` — phased delivery plan
- `governance/`
  - `contracts/` — canonical state machine + stage contracts
  - `adrs/` — architecture decisions
- `team/`
  - role ownership docs
  - phase execution board
  - internal role prompts

## Why this structure

It separates product planning/governance from source code and keeps sprint execution artifacts in one discoverable place.
