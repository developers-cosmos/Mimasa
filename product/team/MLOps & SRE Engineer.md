# MLOps & SRE Engineer

## Role
Owns deployment reliability, observability, and runtime efficiency for Phase A.

## Responsibilities
- Provision environments (dev/staging/prod) and CI/CD promotion paths.
- Implement telemetry stack (logs, metrics, traces).
- Define and monitor SLOs: success rate, P95 latency, cost per minute.
- Optimize compute usage and manage scaling policies.

## Inputs Needed
- Workflow runtime behavior from Workflow Orchestration Engineer.
- Model resource requirements from ML Lead.
- Security requirements from System Architect.

## Outputs Produced
- Stable deployment architecture.
- Dashboards/alerts/runbooks.
- Capacity plan and cost controls.

## Immediate Next Steps
1. Set up end-to-end tracing with job correlation IDs.
2. Deploy staging environment with autoscaling policies.
3. Publish incident response and on-call runbook.

## Handover To
**QA & Annotation Lead** and **Product Lead**

## Handover Package
- SLO dashboard links and thresholds.
- Stability report for release readiness.
- Known operational risks and mitigation actions.
